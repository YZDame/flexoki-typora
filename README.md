# Flexoki for Typora

Four Typora themes based on the [Flexoki palette](https://stephango.com/flexoki):

- Flexoki Light
- Flexoki Dark
- Flexoki Wenkai Light
- Flexoki Wenkai Dark

## Install

1. Download and unzip `flexoki-typora.zip` from [Releases](https://github.com/YZDame/flexoki-typora/releases/latest).
2. In Typora, open the theme folder under **Preferences / Appearance**.
3. Copy the four CSS files and the `flexoki/` folder into the theme folder.
4. Restart Typora and pick a theme from the **Themes** menu.

For the Wenkai variants, install [LXGW WenKai Mono or LXGW WenKai](https://github.com/lxgw/LxgwWenKai/releases/latest).
